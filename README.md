# Expense Tracker

Sistema de gestión financiera personal desarrollado con:

- .NET 10
- Modular Monolith
- Vertical Slice Architecture
- PostgreSQL
- Redis
- Docker
- RabbitMQ
- OpenTelemetry
- Grafana
- Clean Architecture principles

## Objetivos

- Registrar gastos
- Analizar hábitos financieros
- Generar métricas inteligentes
- Aprender arquitectura moderna backend
